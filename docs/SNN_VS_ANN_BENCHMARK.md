# ⚡ vs 🤖 Live SNN vs ANN Benchmark Guide

The simulator now includes a live **SNN vs ANN Side-by-Side Benchmark** (accessible via the `⚡ vs 🤖 SNN vs ANN Benchmark` tab).

This mode trains a **Spiking Neural Network (LIF + Surrogate Gradient BPTT)** and an equivalent **Standard Artificial Neural Network (ReLU MLP + Backprop)** simultaneously on the exact same dataset, allowing you to directly contrast their decision boundaries, convergence, and hardware energy consumption.

---

## 1. Direct Model Architecture Comparison

Both models share the exact same structural topology:

$$\mathbf{2 \text{ Inputs } (x, y)} \longrightarrow \mathbf{16 \text{ Hidden Neurons}} \longrightarrow \mathbf{2 \text{ Output Classes}}$$

| Feature | ⚡ Spiking Neural Network (SNN) | 🤖 Standard ANN (ReLU MLP) |
| :--- | :--- | :--- |
| **Activation Function** | Binary Heaviside Step $\Theta(V - 1.0) \in \{0, 1\}$ | Continuous $\text{ReLU}(z) = \max(0, z)$ |
| **Data Representation** | 1-Bit discrete binary spikes | 32-Bit floating-point scalars |
| **Time Steps** | Temporal sequence $T = 16$ | 1 single instantaneous step ($T = 1$) |
| **Hidden State** | Leaky membrane potential $V(t)$ with reset | Static scalar layer output $h$ |
| **Optimization** | BPTT with Fast-Sigmoid surrogate gradient | Standard backpropagation |

## 2. What the Dual Canvases Show

### ⚡ Left Canvas: Spiking Neural Network (SNN)
* **Visual Theme**: Electric Cyan vs Orange.
* **Decision Boundary**: Generated by counting spikes fired by the two output LIF neurons over 16 time steps.
* Notice how the spiking decision boundary has subtle organic contours resulting from temporal integration thresholds.

### 🤖 Right Canvas: Standard ANN (ReLU MLP)
* **Visual Theme**: Emerald Green vs Orange.
* **Decision Boundary**: Generated by standard continuous float logits:
  $$y = \text{Softmax}(W_2 \cdot \text{ReLU}(W_1 \cdot \mathbf{x} + b_1) + b_2)$$
* Notice the piecewise-linear decision boundary characteristic of ReLU activations.

## 3. Real-Time Hardware & Energy Metric Table

When you click **"Train Both Simultaneously"**, both networks train on each sample in real-time. The metric table updates live:

1. **Operations per Inference**:
   * **ANN**: Requires **$146$ dense FLOPs** (Multiply-Accumulate, or MAC) per sample because every weight is multiplied by a floating-point activation.
   * **SNN**: Requires **sparse Synaptic Operations (SOPs)**. Because non-firing neurons output $0$, the hardware does nothing. If a neuron fires ($1$), it only performs an **addition** ($W_{ij}$ added to voltage), completely bypassing floating-point multipliers!
2. **Dynamic Energy Consumption**:
   * On neuromorphic CMOS hardware (like Intel Loihi or BrainScaleS), a 32-bit floating-point multiplication consumes $\approx 4.6\text{ pJ}$, while an integer/fixed addition consumes only $\approx 0.9\text{ pJ}$.
   * Because of sparsity and multiplication-free math, the SNN uses **$10\times$ to $25\times$ less dynamic energy** while reaching comparable classification accuracy!
